## How to tell the version

Please check the version of the system working on your SP-404MKII before downloading the archive file.

1. Hold down [ SHIFT ] and tap the pad [ 13 ]. The "UTILITY MENU" screen appears.
2. Turn the [ VALUE ] (PUSH ENTER) knob to select "SYSTEM", then press the [ VALUE ] knob.
3. Turn the [ CTRL 3 ] knob all the way clockwise. The version information is displayed on the screen.
4. Press [ EXIT ] to go back to the initial screen.

## Update history (5.00–5.52)

[ Ver.5.52 ] JUN 2026

The version number has been updated due to management-related circumstances. Product specifications are unaffected.

[ Ver.5.51 ] APR 2026

Bug Fixes The following bugs have been fixed.

- The system may hang during certain operations.
- When selecting a folder, the icon to move to the parent directory does not appear.

[ Ver.5.50 ] APR 2026

Functionality Improvements

- SIDE CHAIN COMPRESSION has been added. Please refer to the "Reference Manual" for detailed information in the [ Owner's Manuals. ].
- SDXC cards in Microsoft exFAT format were supported.

[ Ver.5.00 ] APR 2025

Functionality Improvements

- You can now operate the Serato DJ from the SP-404MKII. Please refer to the "Using Serato DJ with the SP-404MK2" for detailed information in the [ Owner's Manuals. ].
- The current settings (how to start resampling) are now shown when resampling.
- SKIP BACK SAMPLING can now be used in DJ MODE (PAD Mode).
